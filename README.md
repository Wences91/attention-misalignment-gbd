# Attention Misalignment in Global Burden of Disease: Mapping Health Needs through Research and Public Attention

This repository contains the full analytical framework, data, and code for the ongoing project **“Towards mapping health needs: the misalignment of health risks, research efforts and public attention to disease”**, submitted as preliminary results for **STI ENID 2025**.

## Project Summary

This study develops a multidimensional model to investigate the (mis)alignment between three domains of global health:

- **Epidemiological burden** (measured via disease incidence from the Global Burden of Disease 2021),
- **Research efforts** (measured through scientific publications indexed in OpenAlex),
- **Public attention** (measured via Wikipedia pageviews).

The approach enables the comparative analysis of how diseases are represented across clinical, scientific, and societal arenas. The current version focuses on a subset of **mental disorders** from the GBD hierarchy between **2016 and 2021**.

> ⚠️ **Note:** This repository supports a research-in-progress. The results herein are preliminary and will be expanded in forthcoming iterations of the project.
